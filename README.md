## 战斗规则（v1.7）

### 棋盘

- 3×3 九宫格，前/中/后三排
- 每方最多 8 个角色，至少留 1 空位
- 前排 ⚔ 标记，双方前排相对排列（象棋式对位）

### 战斗流程

- 自动战斗（100ms/帧的累积器驱动）
- 1x / 2x / 4x 速度切换
- 攻击初始间隔 = 攻速×(0.5~1.0)，避免 0s 出手
- 技能起始冷却 = CD×50%（龙族额外×40%）
- 施法可被打断（控制/攻击/伤害三级）

### 伤害公式（v5.1）

```
物理/魔法伤害：
  原始伤害 = 总攻击力 × 技能倍率 + 固定附加
  防御减伤率 = min(对应防御 / (防御 + 200), 80%)
  前排减伤 = ×0.9（若目标在前排）
  其他减伤 = (1 - Σ百分比减伤)
  格挡 = 触发则减对应防御/5(兽族) 或 /7(其他)
  暴击 = 基础5%，×1.35
  最终 = max(中间 - 格挡, 0)

纯粹伤害：
  原始 → 前排0.9 → 其他减伤
  不计算防御减伤、不格挡
```

### 命中与闪避

- 基础命中率 100%
- 最终命中率 = min(100, 100 + 命中修正 - 闪避率)，最低 30%
- 闪避生效时伤害全免

### 种族羁绊（3人触发满级）

| 种族 | 效果                                  |
| ---- | ------------------------------------- |
| 兽族 | 攻+25% 防+15% 半血吸血20%             |
| 猎人 | 攻+40% 被切入100%反击（先于切入）     |
| 战士 | HP+50% 每10s免异5s                    |
| 法师 | 敌方魔防-50% **获得30%技能吸血**      |
| 亡灵 | 攻+20% 防+25% 首个阵亡7s后复活+无敌1s |
| 龙族 | 攻+30% 技能起始冷却缩短**60%**        |

### 状态效果

| 状态    | 效果                          |
| ------- | ----------------------------- |
| 眩晕 💫 | 无法行动                      |
| 睡眠 💤 | 无法行动，受击20%提前醒       |
| 石化 🗿 | 无法行动，闪避失效，魔防+100% |
| 冰冻 ❄️ | 无法行动，受治疗-50%          |
| 束缚 🔗 | 禁止 #切入/#移动 技能         |
| 灼烧 🔥 | 攻-10%，每秒受伤害            |
| 诅咒 ☠️ | 攻防-10%，受治疗-25%          |
| 沉默 🔇 | 无法使用技能                  |

## 功能特性

### 阵容配置

- 3×3 九宫格自由摆放，右键移除
- 种族羁绊实时预览
- 存档保存/读取/删除（localStorage）
- 🎲 随机阵容一键生成

### 战斗观察

- 技能暂停聚焦：释放技能时卡片高亮+技能名飘出
- 冷却倒计时 ⏳：CD 中显示剩余秒数
- 伤害数字浮动（物理🔴 / 魔法🟣 / 纯粹⬜）
- 攻击动作：物理→刀割，魔法→抖动
- 状态 emoji：🔥 💫 ❄️ ☠️ 等

### 统计面板

- 伤害/承伤/治疗三标签切换
- 进度条+百分比+排名
- 我方/敌方分开统计

### 调试模式 🐛

开启后日志显示完整伤害计算链路：

```
raw=原始伤害 def=防御值 dr=减伤率%
front=前排后 other=其他减伤后 block=格挡值
```

### 一键复制

将阵容配置 + 战斗统计 + 完整日志复制到剪贴板，方便分享和分析。

## 技术架构

|       层       | 说明                                                      |
| :------------: | --------------------------------------------------------- |
|   **Types**    | 52 接口/枚举，CharacterDef/ArenaUnit/BattleState 三层分离 |
|   **Engine**   | processTick 拆分为 9 子函数，SkillRegistry 脚本驱动       |
|   **Hooks**    | 累积器模式帧循环（解耦帧率与逻辑帧）                      |
| **Components** | 纯展示组件（BattleLog/StatsPanel）与容器组件分离          |

### 数据流

```
阵容配置 → initBattle() → BattleState
                                ↓
       useBattleState (requestAnimationFrame 累积器)
                                ↓
                processTick() → updateStatuses/Casting/Skills/Deaths...
                                ↓
       setState({...stateRef.current}) → React 重渲染
                                ↓
       BattleField + UnitSprite + BattleLog + StatsPanel
```
