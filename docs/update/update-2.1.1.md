## 一、变更说明

### 1. 新增站位受控的跨种族平衡测试脚本

新增 `scripts/positionedBalance.ts`（及 esbuild 产物 `.cjs`），用于回答「兽族是否偏强」并排除站位与小样本的干扰。

- **站位求解**：穷举 8! 排列，只保留「前排 3 人承担 ≥42% 全队坦度」的方案（均分为 37.5%），再按覆盖得分取最优。覆盖得分包含同排友军增益、十字相邻友军增益、敌方同排减益，并对前排坦度 / 后排脆度加权。
- **关键站位结论**：中排中央 `(1,1)` 是全盘覆盖最大的格子（十字相邻 4 人、同排 2 人、敌方同排 3 人）；各族的坦克均落到前排（前排坦度占比 54%~80%），十字相邻光环角色均落到 `(1,1)`。
- **实验设计**：7 族两两对阵，每组**双向各 50 局**（消除先手偏差），另加每族 50 局镜像；同时跑「旧站位」（`batchBalance.ts` 的 ROSTER 顺序硬排）作为对照。合计 4900 场。
- **统计口径**：胜=1 / 平=0.5 / 负=0，Wilson 95% 置信区间；`initBattle` + `processTick` 直接使用当前 `src` 现场打包，不依赖历史 `.cjs` 快照。

运行方式：

```bash
npx esbuild scripts/positionedBalance.ts --bundle --platform=node --format=cjs --outfile=scripts/positionedBalance.cjs
node scripts/positionedBalance.cjs 50 both   # [每组每方向局数] [optimized|legacy|both]
```

## 二、测试结论摘要

- **兽族偏强成立**：优化站位综合胜率 **69.4%**（417/600，95% CI 65.6%~73.0%），旧站位 64.3%，两套站位下均为七族第一，CI 完全不含 50%。
- **但呈极端克制形态**：兽族碾压猎人 98.0%、龙族 90.5%、战士 85.0%、法师 64.0%，却被亡灵 39.5%、圣职者 39.5% 反制；场均输出 95,479 为七族最高，场均承伤仅 64,798。
- **强势来源（机制层）**：`yl` 狼吼全兽族攻 +30% 与 `hl` 怒吼敌方全体攻 -20%×8s 同时开场；`dxm` 同排 CD-18%、`zzx` 敌方同排封锁 8s；`pp` 15460 HP 超模前排；兽族 4 档羁绊。
- **站位是强混淆变量**：优化站位使战士 +23.2pp、法师 -17.7pp、圣职者 -16.8pp，兽族 +5.2pp。「只测几场」的手工结论不可作为平衡依据。
- **先手偏差存在**：镜像先手胜率 46%~66%，因此双向对局是必要的。
- **其他种族**：猎人 27.7% 为七族最低，法师 32.0% 次之。
